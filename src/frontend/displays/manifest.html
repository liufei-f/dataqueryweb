Manifest rows

Candidate rows in the format of LocusCompare's qtl_manifest.tsv, built from the download locations of saved records: the files were listed and their headers read, fixed rules mapped the columns, and the AI read the paper for context, sample size, ancestry and genome build. The files are then downloaded into the data folder and, when the importer cannot read them as they are, processed into a _processed copy by a plan the AI chose from a fixed set of operations and that passed value checks. Every value shows where it came from; a quote counts only when it was found in the text the AI was given (✓), otherwise it is marked ✗ unverified. Press Build manifest on a paper; builds run on the server one after another, so you can queue several and close the page. When a paper is built, press Check to open its rows, check the evidence, correct a field, then Approve or Reject. Rules {{ rules_version }} are written out in MANIFEST_RULES.md.
